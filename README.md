# Student Birthday Reminder

## Quick Start

### Node.js Script
```bash
node check_birthdays.js
```

### React Component with Server
```bash
npm install
npm run server
```
Then visit http://localhost:3000 and include the BirthdayChecker component.

## Files
- `students.json` - Student data with birthdays
- `check_birthdays.js` - Standalone birthday checker
- `server.js` - Express server for React component
- `BirthdayChecker.jsx` - React component
